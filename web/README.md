# zyCtrlcenter 面板（web）

Vue 3 + Vite 的简易中控面板，四个页签：**监控大屏 / 任务链 / 运行日志 / 系统信息（含协议映射）**。

## 启动

```powershell
cd web
npm install        # 首次
npm run dev        # http://localhost:5273
```

dev server 已配置代理（`vite.config.js`）：

- `/api` → `http://127.0.0.1:28082`
- `/ws` → `ws://127.0.0.1:28082`（WebSocket 实时事件）

指向别的中控（多开调试）：`$env:VITE_CTRL_TARGET="http://127.0.0.1:28083"; npm run dev`

## 打包

```powershell
npm run build      # 产物在 web/dist（静态文件交给任意服务器即可）
npm run preview    # 本地预览产物
```

## 页面说明

| 页面 | 数据来源 | 功能 |
|---|---|---|
| 监控大屏 | `GET /api/status`（3s 轮询）+ WS | 在线/握手/通道/进程卡片；机器人表格（状态/任务/进度/地图/位置/血量/握手/错误码）；状态筛选；添加（支持 `账号:密码`）/移除机器人；单行或全部 启动/停止/重置；「任务失败待处理」清单 |
| 任务链 | `GET /api/chains[?id=]` | 链列表（**文件驱动**）+ 详情统计 + 节点表（形状容错渲染）；指定账号启动/停链/重置 |
| 运行日志 | `GET /api/logs`（种子）+ WS 实时 | 类型/级别筛选、暂停（冻结列表）、自动滚动、清空日志 |
| 系统信息 | `GET /api/protocols` + `/api/status` | 运行信息表、端口约定、协议映射三组表（只读） |

## 设计约定

- **轮询是权威、WS 是加速**：状态每 3 秒从 `/api/status` 全量刷新；WS 事件只做即时修补，避免丢事件导致看板失真。
- WS 自动重连（3 秒间隔）+ 25 秒 ping 保活；中控侧慢客户端会被断开（前端自动重连）。
- 不引入 UI 组件库，样式集中在 `src/styles.css`（暗色主题），便于二次修改。
- 高危操作（重启机器人、移除机器人、清空日志）都有二次确认。
- 业务功能（账号库/抓鬼/游荡等）不在骨架面板内，按 [扩展指南](../docs/02-架构/扩展指南.md) §5 新增页面。
