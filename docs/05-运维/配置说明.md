# 配置说明

## 1. 端口（默认值，与参考项目错开）

| 配置 | 默认 | 覆盖方式 |
|---|---|---|
| HTTP API | `28082` | `--web-port` / `CTRL_WEB_PORT` |
| 控制通道（单条） | `27200` | `--ctrl-port` / `CTRL_CTRL_PORT` |
| 监听地址 | `127.0.0.1` | `CTRL_WEB_HOST` / `CTRL_CTRL_HOST`（服务器部署设 `0.0.0.0`） |
| 前端 dev | `5273` | `web/vite.config.js` 的 `server.port` |

> 多区模型（服 → 区、切换 vs 应用、每区独立部署目录）见 [多区配置](多区配置.md)。

## 2. 配置来源优先级（从高到低）

| 层 | 载体 | 内容 | 生效时机 |
|---|---|---|---|
| 1 | CLI 参数 | `--web-port` `--ctrl-port` `--deploy` `--data-dir` `--base-dir` `--auto-robot` `--kill-robots` `--api-token` | 启动时 |
| 2 | 环境变量 | `CTRL_WEB_PORT` `CTRL_CTRL_PORT` `CTRL_WEB_HOST` `CTRL_CTRL_HOST` `CTRL_DEPLOY_DIR` `CTRL_DATA_DIR` `CTRL_RUNS_KEEP_DAYS` `CTRL_RUNS_MAX_MB` `CTRL_LOG_KEEP_DAYS` `CTRL_GAME_VERSION` `CTRL_NEWBIE_MAX_LEVEL` `CTRL_AUTO_RESTORE` `CTRL_GHOST_NAV_CHAIN` `CTRL_GHOST_BASE_CHAIN` `CTRL_GHOST_DAILY_LIMIT` `API_TOKEN` | 启动时 |
| 3 | `config.local.json`（**不入库**） | `{"api_token": "..."}`；占位符 `CHANGE_ME*` 视为未配置 | 启动时 |
| 4 | 内置默认（`internal/config/config.go`） | 端口、路径、默认链 ID、默认密码、保留窗口、熔断阈值 | 启动时 |

> 配置**只解析一次**（启动时），运行期只读；改配置需重启中控。

## 3. 内置默认值一览

| 配置项 | 默认 | 说明 |
|---|---|---|
| `DefaultChainID` | `newbie_full` | 请求未带 `chain_id` 时使用（仅透传，不含链数据） |
| `AutoRestore` | `false` | **恢复引擎总开关**：中控重启/机器人重连后按意图自动补发 `start_chain`/`ghost_start`。默认关（会真给机器人发命令）；`CTRL_AUTO_RESTORE=1` 打开。面板仍可随时用「立即补发」手动触发（不受此开关限制，但受冷却/熔断约束） |
| `NewbieMaxLevel` | `31` | **新手链等级阈值**：等级 ≥ 此值（或链已完成）→ 判抓鬼，否则新手链优先；环境变量 `CTRL_NEWBIE_MAX_LEVEL`，口径与机器人端 `config.start_chain_done_level` 一致 |
| `GhostNavChainID` | `zhongkui_nav` | **抓鬼专属数据文件名**（`ghost_maps`/`ghost_map_pos`/`maps`）：抓鬼时与基座链组装后随命令下发；缺失或地址不全即硬失败（不发命令）。环境变量 `CTRL_GHOST_NAV_CHAIN`。见 [链数据](链数据.md) §2.1 |
| `GhostBaseChainID` | `newbie_full` | **抓鬼导航的基座链**：提供 `npcs`/`map_grids`/`dijkstra`/`grid_cell`/`item_meta`（口径同参考实现 `ghost_nav_payload`）。环境变量 `CTRL_GHOST_BASE_CHAIN` |
| `GhostDailyLimit` | `50` | **抓鬼每日上限**：随 `ghost_start` 下发（与机器人默认/参考实现一致）。环境变量 `CTRL_GHOST_DAILY_LIMIT` |
| `AutoRegisterPrefix` / `Suffix` / `Pad` | `robot` / `@xy3.com` / `7` | **定时任务"没号时自动注册"的命名口径**（前缀 + 递增序号 + 后缀，序号按池内同前缀最大值 +1）。环境变量 `CTRL_AUTO_REGISTER_PREFIX` / `_SUFFIX` / `_PAD`。见 [定时自动任务](../02-架构/定时自动任务.md) |
| `DefaultAccountPassword` | `123456` | `robots/manage add` 未给密码时使用；账号验证未给密码时也用它兜底 |
| `GameVersion` | `58740022` | 客户端协议版本：账号可用性验证的 `101 版本验证` 用（`CTRL_GAME_VERSION`；接口可按次传 `version`） |
| `AutoRemoveOnDone` | `true` | `chain_done`/`ghost_done`/`ghost_offline` 是否自动下机（见 [事件与数据流](../02-架构/事件与数据流.md) §3） |
| `RunsKeepDays` | `30` | 运行历史保留天数（`CTRL_RUNS_KEEP_DAYS`） |
| `RunsMaxMB` | `500` | 单日运行历史熔断阈值（`CTRL_RUNS_MAX_MB`） |
| `LogKeepDays` | `30` | 应用日志保留天数（`CTRL_LOG_KEEP_DAYS`） |
| `AutoStartRobot` | `false` | 是否启动时拉起机器人（`--auto-robot`） |
| `KillRobots` | `false` | 重启机器人时是否清残留同名进程（`--kill-robots`） |
| `RobotImageName` | `robot_single_robot.exe` | Windows 下 tasklist/taskkill 用的镜像名 |

## 4. 路径

| 路径 | 默认 | 说明 |
|---|---|---|
| 项目根 `BaseDir` | 当前工作目录 | `--base-dir` 可改（**从项目根启动**，或用 run 脚本） |
| 数据目录 `DataDir` | `<项目根>/data` | `--data-dir` / `CTRL_DATA_DIR` |
| 多区配置 `zones.json` | `<数据目录>/zones.json` | 服/区定义（首次启动写入种子）；随数据目录联动 |
| 链数据目录 `ChainDir` | `<数据目录>/chains` | 随数据目录联动 |
| 日志目录 `LogsDir` | `<项目根>/logs` | — |
| 机器人程序 `RobotExe` | `<部署目录>/robot_single_robot.exe` | 部署目录由 `--deploy` 或自动探测（见 [部署与启动](部署与启动.md) §2） |

## 5. 鉴权（可选）

1. 启用：`--api-token <token>` 或 `API_TOKEN` 或 `config.local.json` 的 `api_token`；
2. 校验：请求头 `Authorization: Bearer <token>` 或 `X-API-Token: <token>`，不匹配返回 401；
3. 保护范围：**只保护高危写接口**（`logs/clear`、`robots/manage`、`robot/restart` 与使用方新增的破坏性接口），
   读接口与 `start`/`stop`/`reset` 不保护，避免前端 break。

## 6. 改配置的三种常见需求

| 需求 | 做法 |
|---|---|
| 换端口（避免与别的服务冲突） | `run_ctrlcenter.bat --web-port 28083 --ctrl-port 27201` |
| 加/改区、切换当前区、把区应用到机器人 | 面板「系统信息」页；或 `/api/config*`（见 [多区配置](多区配置.md)） |
| 服务器部署对外服务 | 设 `CTRL_WEB_HOST=0.0.0.0`、`CTRL_CTRL_HOST=0.0.0.0` 后启动，放行端口（每个区一个控制端口） |
| 延长日志保留 / 放宽熔断 | 设 `CTRL_RUNS_KEEP_DAYS=90`、`CTRL_RUNS_MAX_MB=1024` 后重启 |
| 客户端版本号变了（验证账号报"版本验证失败"） | 设 `CTRL_GAME_VERSION=<新版本号>` 后重启，或在 `/api/accounts/verify` 里按次传 `version` |
