# 账号池

> 中控侧的账号账本：**导入自 Python 中控的账号库**，运行期由中控读写自己的 JSON 池。
> 实现：`internal/services/accounts`（池）+ `tools/import_accounts.py`（导入）。

## 1. 数据从哪来（"数据没有导入吗" → 现在导入了）

| 项 | 说明 |
|---|---|
| 源库（ps 侧） | `E:\robot_accounts\robot_accounts.db`（SQLite，Python 中控在写） |
| 导入命令 | `python tools/import_accounts.py`（可选参数：db 路径、输出路径） |
| 导入产物 | `data/accounts.json`（**中控读这个**，当前 5005 个账号，约 5.6MB） |
| 数据库文件副本 | 另有 `data/robot_accounts.db`（2.5MB，用 SQLite 在线备份复制，供离线查阅） |

池里每个账号包含：`name / password / level / role_name / chain_done / task_type / note / fpp / done`，
以及 **按区的状态** `zones: {"47.96.8.240:2300": {usable, verified, msg, level, role_name, chain_done, fpp, done}}`
（来自库里的 `account_server_state`，即 Python 中控历次"验证"的结果）。

**重新导入**：源库更新后重跑一次导入命令即可 —— 中控按文件 mtime 自动热更新，**不用重启**。

## 2. 池的语义（与运行时状态的关系）

| 数据 | 来源 | 是否落盘 |
|---|---|---|
| 池（账号/密码/区可用性/等级账本） | `data/accounts.json` | ✅ 中控每次变更原子写回 |
| 在线/状态/地图/坐标/背包/守护 | 机器人事件 → `state` | ❌ 运行时数据，不落盘 |
| 该区的可用性（usable） | 导入的库 + 将来的"重新验证" | ✅ |

> ⚠️ **账号是按区可用的**：同一个号可能在 `:2300` 可用、在 `:2400` 不存在（登录报 `errno=100`）。
> 选号请用「按区可用」过滤（面板筛选或 `GET /api/accounts?zone=<host:port>&usable=1`）。

## 3. 接口

| 方法 | 路径 | 说明 |
|---|---|---|
| GET | `/api/accounts?zone=&usable=1&keyword=&online=1&limit=&offset=` | 池列表（**池 + 运行时状态合并**；含统计与导入元信息；**不下发密码**） |
| GET | `/api/accounts/stats?zone=` | 池统计（total/assigned/usable/chain_done + 在线数） |
| POST | `/api/accounts/add` | `{accounts\|names, password?, zone?, note?}` 加号入池（**可选鉴权**） |
| POST | `/api/accounts/remove` | `{accounts}` 从池删号（不动游戏服上的号）（**可选鉴权**） |
| POST | `/api/robots/batch` | 批量上下线（见 §4）（**可选鉴权**） |

## 4. 批量上下线（`POST /api/robots/batch`）

```jsonc
{
  "action": "online",           // online | offline
  "accounts": ["robot0001000@xy3.com"],  // 省略 = 自动选号
  "zone": "47.96.8.240:2300",   // 选号按该区可用性过滤（省略=当前区的游戏服地址）
  "limit": 20,                  // 自动选号上限（默认 20，硬上限 500）
  "chunk": 10,                  // 每条命令带几个账号（默认 10）
  "interval_ms": 500,           // 批间隔（默认 500ms，避免登录风暴）
  "only_usable": true           // 只选可用号（默认 true）
}
```

- **上线**：选号（跳过已在线）→ 分批 `robot_manage add`（密码由服务端从池里取，**不下发到前端**）→ 返回 `{requested, sent, chunks, accounts}`；
  - 自动选号口径（2026-09-23 起）：**从没上过线最前 + 最久未上线优先 + 同值随机平局**
    （`Pick` 按 `last_online` 排序；上线下发成功后由 `TouchOnline` 回写记账）——修掉旧口径
    "按账号名升序取前 N"导致的"永远挑名字最前那批"偏置；
- **下线**：分批 `robot_manage remove`，并在中控本地立即标记移除（防心跳复活）；
- 每次批量操作都写运行历史（`api` / `robots_batch`），面板日志页可查。

## 5. 面板

「账号池」页：统计卡（池内/该区可用/当前在线/已勾选）、筛选（区/可用/在线/关键词）、
勾选 + 批量上线/下线/删号、加号入池（可带 `账号:密码` 与分配区）；表格显示
`账号 / 等级 / 角色 / 区可用 / 验证信息 / 在线 / 状态 / 运行时区 / 是否已设密码 / 备注`。
