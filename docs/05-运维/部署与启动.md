# 部署与启动

> 端口/部署步骤只出现在本文件与 [配置说明](配置说明.md)。首次上手先看 [快速开始](../01-总览/快速开始.md)。

## 1. 系统组成

| 组件 | 位置 | 端口 | 说明 |
|---|---|---|---|
| 前端面板 | `web/`（Vue3 + Vite） | **5273** | dev server，proxy `/api`、`/ws` → 28082 |
| 中控 HTTP API | `zyctrlcenter.exe`（或 `go run .`） | **28082** | 只返回 JSON，不提供 HTML 面板 |
| 中控 TCP 通道 | 同一进程内 | **27200** | 中控 ↔ robot 控制通道（JSON-lines，单连接） |
| robot 进程 | `<deploy>/robot_single_robot.exe` | — | 默认不由中控拉起（`--auto-robot` 开启） |
| 游戏服务端 | 外部 | 2300 | 机器人直连（中控不涉及） |

## 2. 前置条件

1. 安装 **Go 1.22+**（Windows 可用 winget：`winget install GoLang.Go`）；
2. 机器人端 `script/config.py` 的 `ctrl_server_ip/port` 指向本机 **27200**；
3. 端口 28082/27200 未被占用（被占用时会明确报错，见 §5）；
4. 机器人程序路径可用 `--deploy` 指定；默认探测顺序：
   `<项目根>/deploy/single_robot` → `<项目根>/../xm/2d-xiyou-server/robot/deploy/single_robot`。

## 3. 启动

```powershell
run_ctrlcenter.bat                                # 编译 + 启动（默认端口，不接管机器人进程）
run_ctrlcenter.bat --auto-robot                   # 启动时拉起机器人进程
run_ctrlcenter.bat --auto-robot --kill-robots     # 启动前按镜像名清理残留机器人进程

cd web; npm install; npm run dev                  # 前端 http://localhost:5273
```

手写等价命令：

```powershell
go build -o zyctrlcenter.exe .
.\zyctrlcenter.exe --web-port 28082 --ctrl-port 27200
```

## 4. 部署形态

- **A. 中控与机器人在同一台 Windows**（默认形态）：`run_ctrlcenter.bat` + 前端 dev server。
- **B. 中控在服务器、机器人分散**：`CTRL_WEB_HOST=0.0.0.0`、`CTRL_CTRL_HOST=0.0.0.0`，放行 28082/27200；
  各机器人 `config.py` 指向服务器 IP。
- **C. 前端静态部署**：`cd web && npm run build` → 把 `web/dist` 交给任意静态服务器；
  跨机访问时用 `VITE_CTRL_TARGET` 指向中控（或自行给 `web/src/api.js` 加 base URL）。

## 5. 多开隔离（互不干扰）

```powershell
zyctrlcenter.exe --web-port 28083 --ctrl-port 27201 --data-dir data_2
```

要点：
- `--data-dir` 隔离运行历史/单 bot 日志/链数据（配置与账号不需要隔离——骨架层不持久化业务数据）；
- 机器人端 `config.py` 的 ctrl 端口改成 27201 才能连第二个中控；
- 不加 `--kill-robots` 就不会动第一个中控的机器人进程。

## 6. 停止与清理

1. 面板「全部停止」= 停链（机器人保持在线）；
2. 停中控：控制台 `Ctrl+C`（会优雅关闭 HTTP 服务并落盘日志）；
3. 清日志：停中控后删除 `logs/`、`data/runs_*.jsonl`、`data/bot_logs/`；或面板「清空日志」。

## 7. 端口冲突时的表现（设计如此）

| 冲突 | 表现 |
|---|---|
| HTTP 端口被占用 | 启动即 **FATAL 退出**，提示 `HTTP API 端口无法监听 …（用 --web-port 换端口）` |
| 控制通道端口被占用 | 重试 15 次（兼容「重启中控」时旧端口未释放），失败只告警：面板可用、机器人连不上 |
| 前端 5273 被占用 | Vite 自动换端口（`--strictPort` 可强制失败） |
