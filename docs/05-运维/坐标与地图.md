# 坐标与地图

> 面板上的「坐标」「地图」两列的**口径与数据来源**。实现：`internal/maplib`、`internal/services/event`。

## 1. 坐标口径（像素 → 客户端格子）

| 口径 | 值 | 说明 |
|---|---|---|
| 机器人上报 `pos` | 服务端**像素**坐标，如 `2232, 1368` | 原样保留在 `/api/status` 的 `robots[].pos` |
| 客户端显示 | **格子**坐标 = `像素 / 16` 向下取整，如 `139, 85` | 中控算好放在 `robots[].pos_grid`；面板「坐标(格)」列显示它，悬停看像素 |

- 换算常量：`grid_cell = 16`（1 格 = 16 像素；与参考实现一致，其注释标注"已实测验证"）；
- 可覆盖：`CTRL_GRID_CELL` 环境变量；
- 实时推送：`robot_pos_batch` 每条同时带 `x,y`（像素）与 `gx,gy`（格子）；
- 形状不符不猜：`pos` 不是一个二元数组时原样保留，`pos_grid` 置空。

## 2. 地图名（mapid → 中文名）

| 项 | 值 |
|---|---|
| 数据文件 | `data/maps.json`（**131 张图**，随项目入库） |
| 来源 | 游戏配置 `config/map.csv` 的前两列（`map_index`, `map_name`） |
| 生成命令 | `python tools/export_maps.py <map.csv> [out.json]` |
| 接口 | `GET /api/maps` → `{count, grid_cell, source, maps:{mapid: 名称}}`（面板缓存 60s） |
| 面板显示 | `长安东市集(11)`；表里没有的 id 回退显示 `#11` |

刷新地图表（服务端改图/加图后）：

```powershell
& "<python.exe>" tools\export_maps.py "F:\ZyBin\xm\2d-xiyou-server\config\map.csv" "data\maps.json"
```

> 中控**热更新**：`data/maps.json` 改动后无需重启（按文件 mtime+size 自动重载），面板最多 60 秒后刷新。

## 3. 地图可视化（面板「地图」页）

| 项 | 说明 |
|---|---|
| 网格来源 | 游戏配置 `map.csv` 的 `block_file` 列 → `map_file/blockfile/<file>`（二进制：前 8 字节 uint32 小端 = 宽/高，第 9 字节起每行 w 个 `0/1`，`1`=阻挡） |
| 配置目录 | 自动探测 `<项目根>/../xm/2d-xiyou-server/config`；可用 `--game-config` / `CTRL_GAME_CONFIG_DIR` 覆盖 |
| 接口 | `GET /api/map/grid?mapid=11` → `{ok, mapid, name, grid:{w,h,rows}, grid_cell, available, config_dir}`（按需读取 + 内存缓存 30 张 + map.csv 变更自动重载） |
| 页面 | 下拉选图（**有在线机器人的图排前**）、缩放（2~8 px/格）、Canvas 画底图（阻挡深/可走浅）+ 机器人点位（**颜色 = 状态**，站在阻挡格标红）|
| 交互 | 点位平滑插值跟随（rAF）；**点击点位 → 右侧详情**：角色/等级/状态/区/地图/坐标(格)+像素/任务/最近错误、HP/MP 条、**守护**（等级/忠诚/亲密度/HP/出战）、**背包**（37 件真实物品）、摆摊 |
| 点位数据 | `/api/status` 的 `robots[]`（`online && mapid == 选中图`），3 秒轮询刷新 |

> 详情里的背包/守护直接来自机器人上报（`bag`/`summons`/`booth`），字段形状见
> [控制通道协议](../03-协议/控制通道协议.md) §4。**物品操作**（使用/出售/丢弃）尚未实现，见 [账号池](账号池.md) §6。

## 4. 常见问题

| 现象 | 原因 | 处理 |
|---|---|---|
| 地图列显示 `#11` | 地图表里没有该 id / 表未加载 | 确认 `data/maps.json` 存在且有该 id；启动日志的 `[MAPS]` 行会打印条目数 |
| 坐标显示成很大的数 | 看到的是像素（title 里的原始值）或 `grid_cell` 被改错 | 面板「坐标(格)」列是格子；查 `/api/status` 的 `grid_cell` |
| 想按格子画地图/小地图 | 需要每个图的网格与尺寸 | 链数据的 `map_grids`（`data/chains/`）与 `map.csv` 的 `mapwidth/mapheight/mapcalc` 可用 |
