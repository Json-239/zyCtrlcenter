# 目录结构

```
zyCtrlcenter/
├── main.go                    入口：解析配置 → 装配 → 启动 → 优雅退出
├── go.mod                     模块定义（零第三方依赖）
├── README.md                  项目门面（快速开始 + 结构 + 文档索引）
├── run_ctrlcenter.bat         编译并启动（参数透传）
├── run_tests.bat              一键测试（vet + test + 可选 race；退出码汇总三者）
├── config.local.json          本地覆盖配置模板（api_token，不入库）
│
├── internal/                  实现（按领域分包，禁止反向依赖）
│   ├── config/                集中配置（CLI > 环境变量 > config.local.json > 默认）
│   ├── logging/               应用日志：logs/ctrlcenter_YYYYMMDD.log（日期级 + 保留窗口）
│   ├── store/                 运行历史：data/runs_YYYYMMDD.jsonl + 单 bot 日志（日期级）
│   ├── state/                 全局状态容器（机器人表/已移除/当前游戏服，方法级加锁）
│   ├── ctrl/                  控制通道：TCP 单连接、接管、命令下发（事件带当前区标记）
│   ├── wsutil/                最小 WebSocket 服务端（握手 + 文本帧 + ping/pong/close）
│   ├── chainlib/              链数据：文件驱动加载 + 未知字段/形状原样透传
│   ├── maplib/                地图名表 + 坐标口径（像素/16 → 格子）+ 地图网格（阻挡位图，grid.go）
│   ├── services/
│   │   ├── accounts/          账号池（导入自 Python 账号库；列表/统计/选号/增删/区状态）
│   │   ├── zones/             多区配置（服→区注册表 + 切换/落盘 + 写机器人 config.py）
│   │   ├── event/             事件处理（表驱动，按区归属）+ 逐区状态轮询 + 位置合并
│   │   └── process/           机器人进程管理（单进程：拉起/停止/重启/探测）
│   └── api/                   HTTP 路由（含 /api/config*）+ WS 广播 + 可选鉴权 + 协议映射表
│
├── test/                      测试（规范见 docs/04-测试/）
│   ├── README.md              测试库总索引
│   ├── testsupport/           共享基座（夹具/假机器人/临时环境/等待断言）
│   ├── fixtures/
│   │   ├── events/*.json      报文夹具（真实抓包 + 显式构造，带 provenance）
│   │   └── chains/*.json      链数据夹具（真实导出裁剪）
│   ├── store/ ctrl/ event/ api/ chainlib/ wsutil/ config/   各模块用例 + README
│   └── fixtures/              夹具元测试（provenance 强制校验）
│
├── docs/                      文档库（唯一入口 docs/README.md）
│   ├── 01-总览/ 02-架构/ 03-协议/ 04-测试/ 05-运维/ 06-参考/
│
├── tools/                     运维小工具
│   ├── test_report/           **测试报告工具（Go）**：跑 vet+全量测试 → 写报告与 JSON + 校验覆盖现状数字
│   ├── fixlanding/            抓鬼落点修正（Go）：挑同图可走坐标 / BFS 最近可走格
│   ├── import_accounts.py     **导入账号库 → 账号池** data/accounts.json（中控读它）
│   ├── inspect_accounts.py    账号库概览 / 按区可用账号 / 单账号详查
│   ├── patch_robot_config.py  改部署目录 config.py 的账号段起点（只动数字字面量）
│   └── export_maps.py         从游戏 config/map.csv 导出地图名表 data/maps.json
│
├── deploy/zones/<区名>/        旁路验证用的**副本部署目录**（排除日志，~14MB；可选）
│
├── data/                      运行时数据（不入库，data/chains 除外）
│   ├── zones.json             多区配置：服/区定义 + 当前区（首次启动写种子）
│   ├── maps.json              地图名表（map_index → 名称，131 张；tools/export_maps.py 导出）
│   ├── accounts.json          账号池（5005 个号 + 按区状态；tools/import_accounts.py 导入）
│   ├── robot_accounts.db      账号库副本（来自 Python 中控；只读，见 docs/05-运维/账号库.md）
│   ├── runs_YYYYMMDD.jsonl    运行历史（日期级）
│   ├── test_report.json       最近一次 tools/test_report 的结果（面板「模块地图」页读它；不入库）
│   ├── bot_logs/<账号>/runs_YYYYMMDD.log
│   └── chains/                链数据（可选资产，随项目入库：README + _example.json）
│
├── logs/                      应用日志（不入库）
│   └── ctrlcenter_YYYYMMDD.log
│
└── web/                       前端面板（Vue3 + Vite）
    ├── vite.config.js         端口 5273 + proxy /api、/ws → 28082
    └── src/
        ├── api.js             fetch 封装 + WS 自动重连
        ├── store.js           共享状态（3s 轮询 + WS 即时修补）
        ├── App.vue            顶栏 + 页签
        └── components/        Dashboard / AccountsView / MapView / ChainView / ModulesView / LogView / SystemView
```

## 命名约定

| 类型 | 约定 | 示例 |
|---|---|---|
| Go 包 | 小写单词，按领域划分 | `internal/services/event` |
| 测试 | `test/<被测模块>/<模块>_test.go`（外部测试包） | `test/event/event_test.go` |
| 测试基座 | 只在 `test/testsupport` | `testsupport.NewTestHandler` |
| 夹具 | `test/fixtures/<类别>/<名称>.json`（带 provenance） | `fixtures/events/error_task_stuck.json` |
| 运行历史 | `data/runs_YYYYMMDD.jsonl`（按日轮转） | — |
| 应用日志 | `logs/ctrlcenter_YYYYMMDD.log`（按日轮转） | — |
| 链数据 | `data/chains/<文件名>.json`；`_` 开头为模板 | `chains/_example.json` |
| 多区配置 | `data/zones.json`（服→区 + 当前区） | — |

依赖方向：`config`/`logging`/`store`/`state`/`wsutil`（基础层）→ `ctrl`/`chainlib` → `services/*`（zones/event/process）→ `api` → `main`。
