# 快速开始

## 0. 前置

- Go 1.22+（`go version` 可查）
- Node 18+（**首次构建面板需要**；面板已构建后可只跑中控）
- 机器人程序连接中控的地址配置（机器人端 `script/config.py` 的 `ctrl_server_ip/port` → 本机 `:27200`）

## 1. 一键启动（推荐）

```powershell
start.bat          # Windows：构建面板 web/dist → 编译中控 → 启动
./start.sh         # macOS / Linux / Git Bash（首次 chmod +x start.sh）
```

打开 **http://127.0.0.1:28082/** 即面板（与 HTTP API 同一地址）：`web/dist` 存在时面板由**中控自身托管**，
不需要另开 `npm run dev`；`web/dist` 缺失时 `GET /` 回落到 JSON 提示（附一键脚本指引）。

脚本做的事：检测 `go` / `npm`（缺失时给安装指引）→ `web/` 下 `npm install`（仅首次或缺 `node_modules`）
→ `npm run build` → `go build -o zyctrlcenter(.exe) .` → 启动中控（默认端口，其余参数原样透传）。

开关：

| 开关 | 作用 |
|---|---|
| `--skip-web` | 跳过面板构建（用已有 `web/dist`）；等价环境变量 `ZYCTRL_SKIP_WEB=1` |
| `--force-web` | 强制重新构建面板；等价环境变量 `ZYCTRL_FORCE_WEB=1` |
| `--restart` | 先结束已在运行的中控再启动 |
| `--web-dist <目录>` | 透传给中控：面板产物目录（默认 `<项目根>/web/dist`；等价环境变量 `CTRL_WEB_DIST`） |

## 2. 只启动中控（不含前端构建）

```powershell
run_ctrlcenter.bat
# 默认：HTTP API http://127.0.0.1:28082、控制通道 127.0.0.1:27200、不自动拉起机器人
```

常用变体：

```powershell
run_ctrlcenter.bat --auto-robot                  # 启动时拉起 robot_single_robot.exe
run_ctrlcenter.bat --auto-robot --kill-robots    # 启动前按镜像名清理残留机器人进程
run_ctrlcenter.bat --web-port 28083 --ctrl-port 27201 --data-dir data_2   # 多开隔离
```

机器人部署目录（`--deploy`）：优先用命令行 `--deploy <目录>`；否则看环境变量 `ZYROBOT_DEPLOY=<目录>`
——**目录存在才**传给中控，不存在则不传并提示（中控回落到内置探测顺序，见
[部署与启动](../05-运维/部署与启动.md) §2）。`run_ctrlcenter.bat` / `start.bat` 在未设置 `ZYROBOT_DEPLOY`
时会尝试相对路径 `..\xm\2d-xiyou-server\robot\deploy\single_robot_zy`（存在才用）。

等价手写：

```powershell
go build -o zyctrlcenter.exe .
.\zyctrlcenter.exe
```

启动后自检：

```powershell
curl http://127.0.0.1:28082/api/status     # 或浏览器打开
```

## 3. 前端开发模式（可选，改面板源码时才需要）

```powershell
cd web
npm install      # 首次
npm run dev      # http://localhost:5273
```

面板四个页签：**监控大屏 / 任务链 / 运行日志 / 系统信息**。
dev server 已配置代理：`/api` 与 `/ws` → `http://127.0.0.1:28082`。

指向别的中控（多开调试时）：

```powershell
$env:VITE_CTRL_TARGET="http://127.0.0.1:28083"; npm run dev
```

> 日常运行不需要这一步：`start.bat` / `start.sh` 构建一次 `web/dist` 后，面板就由中控在 28082 上直接服务。

## 4. 让机器人连上来

1. 确认机器人端 `script/config.py` 里 `ctrl_server_ip/port = "127.0.0.1" / 27200`；
2. 启动机器人进程（自行启动，或用 `--auto-robot` 让中控拉起）；
3. 面板「监控大屏」出现该账号即接入成功（状态 `ONLINE`）。

## 5.（可选）放入链数据

把链数据文件放进 `data/chains/<chain_id>.json`（模板见 `data/chains/_example.json`），
面板「任务链」页即可看到并一键启动。没有文件也能启动——中控只下发 `chain_id`。
详见 [链数据](../05-运维/链数据.md)。

## 6. 验证与测试

```powershell
run_tests.bat          # go vet + 全量测试（可选 race）
```
