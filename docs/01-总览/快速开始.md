# 快速开始

## 0. 前置

- Go 1.22+（`go version` 可查）
- Node 18+（跑前端面板；只用 `vue` + `vite` 两个依赖）
- 机器人程序连接中控的地址配置（机器人端 `script/config.py` 的 `ctrl_server_ip/port` → 本机 `:27200`）

## 1. 启动中控

```powershell
run_ctrlcenter.bat
# 默认：HTTP API http://127.0.0.1:28082、控制通道 127.0.0.1:27200、不自动拉起机器人
```

常用变体：

```powershell
run_ctrlcenter.bat --auto-robot                  # 启动时拉起 robot_single_robot.exe
run_ctrlcenter.bat --auto-robot --kill-robots    # 启动前按镜像名清理残留机器人进程
run_ctrlcenter.bat --web-port 28083 --ctrl-port 27201 --data-dir data_2   # 多开隔离
```

等价手写：

```powershell
go build -o zyctrlcenter.exe .
.\zyctrlcenter.exe
```

启动后自检：

```powershell
curl http://127.0.0.1:28082/api/status     # 或浏览器打开
```

## 2. 启动前端面板

```powershell
cd web
npm install      # 首次
npm run dev      # http://localhost:5273
```

面板四个页签：**监控大屏 / 任务链 / 运行日志 / 系统信息**。
dev server 已配置代理：`/api` 与 `/ws` → `http://127.0.0.1:28082`。

指向别的中控（多开调试时）：

```powershell
$env:VITE_CTRL_TARGET="http://127.0.0.1:28083"; npm run dev
```

## 3. 让机器人连上来

1. 确认机器人端 `script/config.py` 里 `ctrl_server_ip/port = "127.0.0.1" / 27200`；
2. 启动机器人进程（自行启动，或用 `--auto-robot` 让中控拉起）；
3. 面板「监控大屏」出现该账号即接入成功（状态 `ONLINE`）。

## 4.（可选）放入链数据

把链数据文件放进 `data/chains/<chain_id>.json`（模板见 `data/chains/_example.json`），
面板「任务链」页即可看到并一键启动。没有文件也能启动——中控只下发 `chain_id`。
详见 [链数据](../05-运维/链数据.md)。

## 5. 验证与测试

```powershell
run_tests.bat          # go vet + 全量测试（可选 race）
```

测试规范见 [测试规范](../04-测试/测试规范.md)。
