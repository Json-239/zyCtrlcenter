## 2. 骨架层可继续打磨的点（工程质量）

| 项 | 说明 |
|---|---|
| 覆盖率统计 | `go test ./test/... -cover`；需要时接入 CI |
| `-race` | 装 mingw-w64 后 `run_tests.bat` 自动启用（当前本机无 gcc 会跳过） |
| 前端测试 | 引入 Playwright 做一次冒烟（当前人工浏览器验收） |
| 配置热更新 | 目前配置启动解析一次；需要时加 `SIGHUP` 或管理接口 |
| 指标暴露 | `/metrics`（Prometheus 文本格式，标准库可手写） |
| 结构化应用日志 | 目前是行文本；需要时改 JSON（`logging` 单点改动） |
| WS 鉴权 | 当前 WS 不校验 token（读接口同理）；需要时在升级前校验 `?token=` |
| 单行超长报文用例 | `ctrl` 已限长 64KB，补一条测试 |

## 3. 已知限制（明确不做或暂不做）

| 项 | 原因 |
|---|---|
| 中控不碰游戏协议（当前） | 现状：中控只走「与机器人」的通道；**批量注册/验证**需要直连游戏服的注册/登录探测协议（参考实现 `register_robot.py` 392 行），属于待移植（见上表 1、2） |
| 不自动复制机器人部署目录 | 复制数十上百 MB 的目录属运维动作（手工一次即可），见 [多区配置](../05-运维/多区配置.md) §5 |
| 不做业务决策 | 换号/冷却/资格/补位等由使用方实现（[项目简介](../01-总览/项目简介.md) §边界） |
| 不做链数据生产（解析任务 XML） | 本项目只消费链数据文件；生产由上游系统负责（[链数据](../05-运维/链数据.md)） |
| 不内置数据库 | 骨架零依赖；需要时参见 §1 第 7 项 |
| 不提供 HTML 面板（后端只出 JSON） | 前端独立项目 `web/`，可用任意静态服务器托管 |
