## 2. 关键保障（跨模块）

| 保障 | 用例 | 意义 |
|---|---|---|
| 日期级日志 | `test/store::TestCurrentPathIsDateBased` 等 | 路径必须是 `runs_YYYYMMDD.jsonl`，清理/清空/熔断行为固定 |
| 单连接接管 | `test/ctrl::TestNewConnectionTakesOverOld` | robot 重启后命令不会发到僵尸连接 |
| 协议覆盖 | `test/event::TestEventTableCoversProtocolSpec` | 协议表每个事件都有处理分支 |
| 真实数据 | `test/fixtures::TestFixtureProvenance`、`test/chainlib::TestBuildPreservesUnknownFieldsAndShapes` | 夹具来源可查；链数据未知字段/形状不丢 |
| 切区一致性 | `test/api::TestConfigGetAndSwitch`、`TestConfigApplyOtherZoneSwitchesCurrent` | 切换后 `current` 与控制通道事件标记同步；对指定区应用会顺便切当前区 |
| 区标记 | `test/event::TestEventZoneTaggedFromChannel` | 通道打 `_zone`（当前区）→ 状态行/统计按区归属 |
| 写机器人配置 | `test/zones::TestApplyRobotConfigRewritesOnlyThreeKeys`、`test/api::TestConfigApplyWritesRobotConfig` | 只改三个键 + 备份 + 未变不写（真实接口链路）；表达式值跳过不改 |
| 坐标口径 | `test/event::TestPosConvertedToClientGrid`、`test/maplib::TestGridPosClientCoordinate` | 像素→客户端格子（/16 向下取整），原始像素保留、形状不符不猜 |
| 地图名 | `test/api::TestMapsEndpoint`、`test/maplib::TestLoadAndLookup` | 用真实裁剪表校验 `11=长安东市集`；未知 id 回退 `#id` |
| 地图网格 | `test/api::TestMapGridEndpoint` | 用构造的 blockfile 校验 `w/h/rows` 解析与 `mapid` 缺失容错 |
| 账号池 | `test/accounts::TestFilterAndStats`、`TestPickForBatchOnline`、`TestHotReloadAfterReimport` | 真实库裁剪夹具；按区可用过滤、选号跳过在线、重新导入热更新 |
| 批量上下线 | `test/api::TestRobotsBatchOnlineAutoPick`、`TestAccountsAddAndRemove` | 自动选号只选可用号、跳过已在线、密码由服务端取（机器人实收 `[账号,密码]`）、下线本地标记移除 |
| 协议字节一致 | `test/gameproto::TestPackMatchesReferenceFixtureBytes`、`TestBuildRoleFrameMatchesReferenceFixture` | 帧/字段/角色表字节由参考实现生成，**逐字节**比对（不是"看起来差不多"） |
| 批量选号口径 | `test/accounts::TestSelectForVerifyUnverifiedOnlyCountsKnownZoneRows` | "该区的号"=池里有该区记录 |
| 任务链路意图（单链互斥） | `test/intent::TestPlanSingleKindPerAccount`、`TestDecideGhostWhenChainDone`、`test/api::TestIntentsEndpointDecideFlow` | 等级<31→新手链优先、≥31 或已完成→抓鬼、等级未知不登记；**一个账号同一时刻只有一条链**（切换返回 prev 供"先停旧链"） |
| 验证默认=本区全部 | `test/accounts::TestSelectForVerifyZoneScope`、`test/api::TestAccountsVerifyZoneScopeAll` | 默认范围 `zone`（该区有记录的全部，含已验过）+ `limit=0` 不限；无记录的不算"本区账号" |
| 启动=按意图自动分配链 | `test/api::TestStartAutoAssignsByIntent`、`TestStartAutoFallsBackToGivenChain`、`TestStartManualKeepsOldBehavior` | 新手链意图→`start_chain(newbie_full)`、抓鬼意图→`ghost_start`、无意图→回落指定链、空闲不发；逐号回带理由；不传 auto 行为不变 |
| 上线=点选（不用输账号） | `test/api::TestRobotsBatchSelectionTrimsAndDedups`、`TestRobotsBatchOnlineAutoPick`、`TestAccountsAddAndRemove` | 行内一键上下线走同一接口；勾选集合去空白/空串/保序去重；自动挑号只选可用且跳过已在线 |
| 按编号建号 | `test/accounts::TestBuildNamesWithSuffixAndAutoWidth`、`test/api::TestAccountsCreateByNumberSpec`、`TestAccountsCreateInBatchesWithConcurrency` | 前缀+序号补零+后缀生成；自动接续=池内最大+1；分批并发下结果同序 |
| 批量写不丢数据 | `test/accounts::TestNoSaveBatchSurvivesHotReload`、`test/api::TestAccountsCreateByNumberSpec` | 批量写回期间禁止热重载（`dirty`/`BeginBatch`），并发建号的密码必须全部落库 |
| 建号=先验证再注册 | `test/api::TestAccountsCreateReusesExistingAccount`、`TestAccountsCreateDetectsPasswordMismatch` | 已存在且密码对 → **不发注册**、标可用+角色；密码不符 → 不注册、标"存在但不可用" |
| 密码按服通用 | `test/accounts::TestPasswordSharedWithinSameServer` | 同 host 的区共享密码；别的服不共享（回退账号级） |
| 密码只从库里取 | `test/accounts::TestPasswordForPrefersZoneThenAccount`、`test/api::TestAccountsCreateRandomPasswordThenLoginWithStoredPassword` | 建号写随机密码入库 → 登录用库里密码（md5 比对）；取不到明确失败（**没有统一密码**） |
| 注册协议 | `test/gameproto::TestBuildRegisterFrameMatchesFixture`、`test/accountcreate::TestRegisterSendsEightFieldsAndReportsSuccess` | 104 的 8 字段字节与参考实现一致；106→104→700 全链路 |
| 批量任务 | `test/accountverify::TestJobRunsAllAndCallsBackPerAccount` | 进度单调、逐条回调 |
| 账号可用性语义 | `test/accountverify::TestProbeNoAccount`、`TestProbeBadPasswordIsNotUsable`、`TestProbeFreezedIsNotUsable` | 100=不存在、200/300=存在但**不可用**（否则会被反复拉起）；失败绝不判为可用 |
| 默认批量链路 | `test/api::TestAccountsVerifyDefaultsToPoolBatchJob` | 不传 accounts → 按区选号 → 写回池 |
| 失败不改坏结论 | `test/api::TestAccountsVerifyNetworkErrorDoesNotFlipUsable` | 网络失败只写 `验证失败：…`，账号池里的 `usable` 保持原值 |
| 探测资源约束 | `test/accountverify::TestProbeTimeoutWhenNoAck`、`TestProbeStopsOnContextCancel`、`TestVerifyAllKeepsInputOrderAndUsesOneConnPerAccount` | 超时/ctx 取消能提前返回；每账号一条独立连接；结果与输入同序 |
| 命令实收 | `test/api::TestStartDeliversChainFromFile`、`TestRobotsManageAddDeliversPairs` | 断言机器人端**实际收到**的报文，而非仅接口返回 |
| 失败可解释 | `test/api::TestStartWithoutRobotExplainsReason` | 通道未连接必须给出原因 |
| 鉴权 | `test/api::TestOptionalAuthToken` | 默认关闭；开启后 401 / Bearer / X-API-Token 行为固定 |

## 3. 已知未覆盖（骨架层）

| 项 | 原因 | 建议 |
|---|---|---|
| 真实机器人进程联调 | 用例不启动外部进程（铁律 3.2） | 用冒烟脚本手工验证（见 [日志与排障](../05-运维/日志与排障.md)） |
| 真实游戏服探测 | 不该拿生产服做测试 | 用假游戏服（`test/testsupport/gameproto` 侧）覆盖全链路；真实验证在面板点一次即可 |
| GBK 编码 | 零第三方依赖，未内置 GBK 表（**明确报错**，不静默乱码） | 需要时按 `internal/gameproto` 的 `encodeStr/decodeStr` 接入编码表 |
| 跨天日志轮转的真实时钟 | 单测用文件时间戳模拟 | 需要时用注入时钟重构 `store` |
| 单行 >64KB 的截断 | 上行限长 64KB 已实现；**下行大载荷（2MB 级链数据）已有写超时与断连用例**，超长上行截断本身未加用例 | 补 `test/ctrl` 用例 |
| `-race` | 本机无 CGO/gcc 时自动跳过 | 装 mingw-w64 后 `run_tests.bat` 自动启用 |
| 前端 UI | 无前端测试框架（骨架层不做） | 用浏览器人工验收（本轮新增页做了 DOM 断言）；后续可引入 Playwright |
