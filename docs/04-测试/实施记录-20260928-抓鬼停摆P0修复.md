## 5. P1 修复（共享计数残留误伤）——已实施 + 热更（20:05:47）

修复后 NAV 类 stuck 仍 ≈170/h，经 ghost-dive 独立验证确认为**另一个独立机制**（非 P0 复发）：

- 样本 `robot0001000@xy3.com` 19:11：跨图到图 → `重试 4 次(本状态真实第 1 次)` → 追鬼重试可达 → 点击到鬼 NPC → 19:11:47 顶到 `rounds=5` 报 GHOST_STUCK（其实已点到鬼，误伤）。
- 样本 `robot0005050@xy3.com` 19:00（ghost-dive 补）：完整链条到图后**直接 GHOST_STUCK（"重试 5 次"）**，连"重试 4 次(真实第 1 次)"都没打（判据处抢先）。**债务第二来源**：`对话超 30 秒未关闭, 强制关闭回 READY 按本地任务分流(第 4 轮)`——"第 4 轮"=共享 rounds=4，交付/对话路径也在给共享计数充值。
- 机制：`g.rounds` 跨状态共享（对话第 N 轮/降频闸/等鬼回退等多处消费），归零点少；"恢复期债务号"累计到 4 后，任意一次 NAV 超时 → 5 → 误伤。组合分布（17:20-19:49 共享/真实）：2/1=740 最多、4/1=189、3/1=272 等。

**修复**（ghost-dive 精确 diff，最小 2 行；双副本 sha1 `1aa59d61b0946b603c1944e58cd2df47cdf9e89a`）：

```python
_over_r = _nav_r if g.state == "NAV" else g.rounds
if _over_r > 4:
    __stuck(robot_object, g, "状态 %s 重试 %d 次仍无进展" % (g.state, _over_r))
```

- 语义：NAV 用本状态真实计数（干净路径 nav_r 到 3 即由 `__nav_ghost_follow_ok` 清鬼归零，到不了 5 = 不再误伤）；`>4` 防线保留（兜 NAV+无鬼等异常路径）；非 NAV 判据逐字不变。**否决备选**：改共享 rounds 归零点（动它=重演 09-24 教训）。
- 自检：NAV 自检 26→**34 项**（A10-A12 判据钉 / B5 非 NAV 原样 / B6 债务免疫 / B7 防线 / S5-S6 变异判别：判据回退必复现误伤）；`ghost_hunt` A32 断言同步更新（原钉"__stuck 判据不动"，P1 有意变更故随新语义改写）；回归 11 套件全绿。
- 热更：**20:05:47 `reload_reply daily_ghost ok`**（ts=1790597147）。
- 热更后 8.5 分钟：**NAV 类"仍无进展" 0 条**（前窗 169+21/h）；追鬼重试 157（≈1113/h）、完成 228（≈1616/h）保持；无 Traceback。
