## 1. 日志契约

### 1.1 现状即可取证（实施前也能用）

| 层 | 路径 | 格式 | 关键用法 |
|---|---|---|---|
| ① 机器人原始协议 | 线上副本 `.../single_robot_zy/script/diag.log`（轮转 `.1/.2`） | 文本 | `>>> recv msgid=<号> data=[...]` + 下一行 `handler for <号> = <function xxx_handle ...>`；**实测技巧：90072/90365 的 `data` 首元素就是 task_index**（如 `recv msgid=90072 data=[2019511]`）→ 可直接 grep 任务号流转 |
| ② 单号状态流 | `data/bot_logs/<账号>/runs_YYYYMMDD.log`（JSONL） | JSON Lines | `type=robot_state`：`state / task_index / last_task / mapid / pos / done / err_code / err_ts / hp / mp`（偶发 `bag`）；`type=log`：`msg` 文本（如 `走路: (x,y) → (x,y)`、`READY 诊断: ...`） |
| ③ 中控 | `logs/ctrlcenter_YYYYMMDD.log` | 文本 `[TAG]` | 当日实测 tag 分布：`[EVENT]`(5660) `[INTENT]`(3020) `[ROAMPOOL]`(2249) `[WATERLINE]`(1122) `[REGHOST]`(1019) `[RESTORE]`(849) `[AUTOTASK]`(630) `[LEVEL]`(577) `[CTRL]`(216) `[PROC]`(84)；找接取/恢复/暂停先看 `[EVENT]`/`[RESTORE]`/`[AUTOTASK]` |

### 1.2 实施应落地（日志契约＝改造项，命名以实施为准）

> 目的：让剧本 §4 的九条判据**可自动断言**。建议机器人端在状态机里按下列事件打 tag 日志（一行一事件，含账号/轮次/分支/任务号）：

| 建议 tag | 触发时机 | 必须字段 | 服务判据 |
|---|---|---|---|
| `SHD_START` | 收到启动命令 | `share_key / accounts / cmd 原文` | S0 |
| `SHD_ACCEPT_DIALOG` | 张忍慎对话弹出 | `options[] / 选中项文本` | P0-1（验证没点"算了"） |
| `SHD_ACCEPT_OK` | `TASK_ADD` 且号∈白名单 | `task_index / branch(A\|B)` | P0-1 |
| `SHD_KILL_NPC` | 点击明雷匪徒/匪首 | `npc_index / 坐标 / 第几只` | P0-2 / §5.2 |
| `SHD_FIGHT_END` | 战斗结束 | `编队(含 30126?) / win\|lose` | P0-2 / P0-3 |
| `SHD_SUBMIT_OK` | 主任务 FINISH | `task_index / 主键计数` | P0-4 |
| `SHD_TELEPORT` | 收尾传送 | `mapid / pos / 扣费(筋斗云\|100)` | P0-7 |
| `SHD_TAIL_FINISH` | `2028399` FINISH | `计数=10/10` | P0-5 |
| `SHD_COOLDOWN_WAIT` | 掉任务进 600s 冷却 | `buff=2028302 / retry_at / attempt` | P0-6 / §5.1 |
| `SHD_STOP` | 停止 | `reason`（"次数已用完"/"冷却等待超限"…） | P0-5 |

## 2. 采样脚本（已实测可用）

保存为 `tools/sample_status.py`：

```
python tools/sample_status.py <账号> <次数> <间隔秒>
# 单轮 ≈5 分钟：python tools/sample_status.py robot0001006@xy3.com 30 10
```

```python
# -*- coding: utf-8 -*-
"""验收采样：每 N 秒抓一次 /api/status，只留目标号，落 CSV（UTF-8）。只读，不改任何状态。"""
import csv, json, sys, time, urllib.request

account = sys.argv[1]
n, gap = int(sys.argv[2]), int(sys.argv[3])
url = "http://127.0.0.1:28082/api/status"
cols = ["ts", "state", "task_index", "last_task", "mapid", "pos",
        "fight", "stuck_count", "err_code", "money"]
out = "sample_%s.csv" % account.split("@")[0]
with open(out, "w", newline="", encoding="utf-8") as fh:
    w = csv.writer(fh); w.writerow(cols)
    for _ in range(n):
        try:
            with urllib.request.urlopen(url, timeout=5) as r:
                d = json.load(r)
            bot = next((b for b in d.get("robots", []) if b.get("account") == account), None)
            if bot:
                w.writerow([int(time.time()), bot.get("state"), bot.get("task_index"),
                            bot.get("last_task"), bot.get("mapid"),
                            "(%s,%s)" % tuple(bot.get("pos") or (0, 0)),
                            bot.get("fight"), bot.get("stuck_count"),
                            bot.get("err_code") or "", bot.get("money")])
            else:
                w.writerow([int(time.time()), "NOT_FOUND"])
        except Exception as e:
            w.writerow([int(time.time()), "SAMPLE_ERR", str(e)[:60]])
        time.sleep(gap)
print("done -> %s（%d 行）" % (out, n))
```

实测输出示例（2026-09-23 抽验通过）：

```

[1790169606, 'IDLE', 0, 2019511, 45, '(1560,472)', False, None, '', 73]
```

## 3. 硬指标阈值（与剧本 §4 一一对应）

| 判据 | 阈值 | 自动判据（对采样 CSV / 日志） |
|---|---|---|
| P0-1 自然接取 | ≤60s；任务号 ∈ {2028301,2028302} | 日志 `SHD_ACCEPT_OK`（或 diag `recv msgid=90365 data=[<号>...]`）；无人为 `@addtask` |
| P0-2 A 分支 | ≤3 场；首战起 ≤5 分钟 | `SHD_FIGHT_END` 计数 ≤3 且末场含 `30126`；`TASK_FINISH 2028301` |
| P0-3 B 分支 | 巡逻 ≤8 分钟；点击 `13597` 后 1 场 | `TASK_ADD 2028311` 无接取动作；`TASK_FINISH 2028311` |
| P0-4 计数 | 每轮恰 +1 | 逐轮记录主键计数（`90152/90300`）；连续 2 轮增量=+2 |
| P0-5 第 10/10 | 收尾必须 FINISH；随后 STOP | `SHD_TAIL_FINISH` 后 `SHD_STOP`；STOP 后无重接 |
| P0-6 冷却 | 正常 0s；掉任务 600s（≤900s 等待） | 两轮间隔 <60s（正常）；掉任务后 `SHD_COOLDOWN_WAIT` 且 600s 内无"失败" |
| P0-7 传送 | 完成后 ≤10s 落 12 图 | 采样 CSV：`mapid=12` 且 `pos≈(2265,1846)`；`money -100` 或筋斗云 -1 |
| P0-8 无异常 | `stuck` ≤+1/10 分钟；无 `err_code` | 采样 CSV 的 stuck_count 斜率与 err_code 非空 |
| P0-9 奖励 | +500 开元通宝 + `190186`×1 | `money` 前后差；bag 中 `190186` 出现 |
