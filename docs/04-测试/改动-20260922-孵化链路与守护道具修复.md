## 二、守护道具误用修复（TIDY_BAG，已热更）

### 2.1 根因（实测证据）
`daily_ghost.__tidy_bag` 把背包里"非装备非任务"的物品**一律当人物道具** `C2S_USE_ITEM` 使用 →
幻兽丹/亲密丹等 `use_on_summon=yes` 的道具被服务端拒（notice **1268**"未打开守护界面"）**且物品不消耗** →
每个整理轮重试（diag 实测单件刷 16 次、`TIDY_BAG use item` 22115 次、notice 1268 **2432** 次）。

### 2.2 修复
- `__load_item_meta` 解析 `item_param[name=use_on_summon]`；
- 新增纯函数 `is_summon_only_item(item_index, meta_entry, fighting_summon_id)`：
  ① `use_on_summon=yes` → 跳过；② 守护经验丹（101373/101375/190034）**无参战守护**时跳过
  （否则弹"你还未设置第一参战守护呢！"且不消耗 → 同样循环）；
- `__tidy_bag` 的 `to_use` 分支调用该判据（跳过并记 `TIDY_BAG skip summon-only items=N`）。
- 自检：`tools/item_use_selftest.py` **12 项 0 失败**（含反证：幻兽丹在旧行为下会被当人物道具用）。

## 五、游荡档位（profile）—— "站着不动踩不到暗雷"的修复 + 可扩展设计（2026-09-22 增补）

### 5.1 问题
用户反馈：半月岛的号**站着不动**，而"停顿不移动无法触发战斗"（暗雷靠走动踩出来）。
代码实测默认节奏：`stand_ratio` **0.25~0.8**（走完一段后站住的概率）、`stand_min_ms` **25~90s 起**、
`stand_max_ms` 再加 60~180s（**单次最长可停 ~4.5 分钟**）→ 大部分时间在原地 → 孵化进度为零。

### 5.2 修法：游荡档位注册表（可扩展）
`random_walk.py` 新增：

```python
ROAM_PROFILES = {
    "default": {},                              # 既有账号级随机（真人挂机感），不改
    "dense":   {"step_min":260, "step_max":620, # 大步赶路
                "stand_ratio":0.05,             # 几乎不停（原 0.25~0.8）
                "stand_min_ms":800, "stand_max_ms":2500,  # 停 0.8~2.5s（留一点真人感）
                "dither_ratio":0.15, "heading_span":0.6,
                "desc":"密集游荡(孵化踩暗雷/野外打怪)"},
}
def apply_roam_profile(w, name, log=None): ...   # 未知档位 → 回退 default + 记日志（不卡号）
```

- **命令透传**：`random_walk` 命令新增可选 `mode` 字段；中控 `POST /api/random_walk` 透传
  （`{"accounts":[...],"mapid":6,"mode":"dense"}`）；同图补发时**档位变了也会重应用**（可在线切换）。
- **孵化固定 dense**：`mount_egg` 启动游荡时固定 `"mode":"dense"`（孵化必须大面积走动）。
- **后续扩展**（用户已明确方向）：野外挂机刷怪 / 挖宝 / 挖矿 / 打猎 —— 在 `ROAM_PROFILES`
  注册新档位即可（可各自定义步长/停顿/乱点节奏；若需"采集/打猎"专属行为，再在
  `random_walk` 的 tick 里按 `w.profile` 分派动作钩子），**不用改主循环、不用改中控协议**。
- 启动日志带档位：`集合走启动: 目标图 6, 范围 ..., 档位 dense(停5%/步260~620)`。
- 自检：`tools/roam_profile_selftest.py` **16 项 0 失败**（含：default 不覆盖账号级随机、
  dense 参数确实"密"、未知档位回退并记日志、mount_egg 固定 dense 的源码形状）。
