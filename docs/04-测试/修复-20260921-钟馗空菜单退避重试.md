## 2. 根因（代码复核结论）

`on_show_dialog` 里钟馗"无可动作项"（菜单只剩"活动说明/离开"）分两条路径：

```
if first is None and npc_id == BROKER_NPC_ID:            # 旧行号 ~1746
    quest.dialog_open = False; quest.dialog = None; quest.pending = None
    # A) 没钱/没令 (need_token=False / token_no_money / token_fail 达上限)
    if (not need_token) or token_no_money or token_fail >= TOKEN_FAIL_MAX:
        if __note_no_action(robot_object, g, need_token):   # 达 3 次 → 自愈/下线换号
            return True
        __goto(BROKER, 1500)          # 未达上限: 1.5 秒后立即重点钟馗(高频空转)
        return True
    # B) 需买令但菜单无"领取助战令/捉鬼"项
    __need_relogin(robot_object, g, "钟馗菜单无可动作项(仅说明/离开), 重登恢复")   # 立即重登
    return True
```

- **B 路径立即 `__need_relogin`** → 发 `GHOST_DIALOG_STUCK` 事件 → 中控当日卡死计数（`stuck_count`）快速累加；
- 达 3 后中控 churn 防护**不再自动重登/补发** → 该号 `IDLE` 停摆（19:34 的 29 个号即此）；
- A 路径的"1.5 秒立即重点"虽不重登，但几秒内就把 `no_action_rounds` 顶到 3 → 快速下线换号（也是 churn）；
- 两处都没有给"偶发空菜单"任何自愈窗口 —— 这是本次要修的核心。

另一处调用 `on_close_dialog`（旧 ~1947 行，"接取对白结束但任务未到"且已确定没钱/没令时推 `__note_no_action` 到 3 换号）复核结论：**语义不同、无立即重登问题，不改**。

## 3. 修复设计

核心：**空菜单先退避重试（60s / 120s），重登降级为最后手段**。

### 3.1 新常量（L564-565）

```python
BROKER_EMPTY_RETRY_MAX = 2                      # 退避重试上限
BROKER_EMPTY_BACKOFF_MS = (60 * 1000, 120 * 1000)   # 第 1 次 60s, 第 2 次 120s
```

### 3.2 `GhostState` 新字段（L354-357）+ `reset()`（L380-382）

```python
self.no_action_retry = 0      # 连续空菜单退避次数
self.no_action_retry_at = 0   # 下次允许点钟馗的时刻(ms)
# reset(): 两字段归零(重登/新会话重新给退避机会)
```

### 3.3 新函数（L637 起）

```python
def __clear_broker_empty_backoff(g):
    # 拿到正常菜单/接到任务 = 链路恢复: 清零退避与重试计数
    g.no_action_retry = 0
    g.no_action_retry_at = 0

def __broker_empty_waiting(g, now_ms):
    # True = 退避未到期, READY 先不点钟馗(原地等)
    return float(getattr(g, "no_action_retry_at", 0) or 0) > now_ms

def __start_broker_empty_backoff(robot_object, g, quest):
    # 关对话 + 清导航残留 + 设 no_action_retry_at + 回 READY; 返回 False = 重试用尽
    _n = int(getattr(g, "no_action_retry", 0) or 0)
    if _n >= BROKER_EMPTY_RETRY_MAX:
        return False
    _n += 1
    _delay_ms = BROKER_EMPTY_BACKOFF_MS[min(_n - 1, len(BROKER_EMPTY_BACKOFF_MS) - 1)]
    g.no_action_retry = _n
    g.no_action_retry_at = __now_ms() + _delay_ms
    # 关对话 + 清导航残留(退避期原地等, 防"到达钟馗自动点击"在退避期内又弹空菜单)
    quest.dialog_open = False; quest.dialog = None; quest.pending = None
    quest.walk_target = None; quest.dijkstra_route = []
    __set_state(g, "READY", __now_ms())
    __log(robot_object, "warn", "钟馗空菜单: 退避 %ds 后重试(第 %d/%d 次)" % (...))
    return True
```

### 3.4 `on_show_dialog` 空菜单分支（L1806-1836）

```python
if first is None and npc_id == BROKER_NPC_ID:
    quest.dialog_open = False; quest.dialog = None; quest.pending = None
    if (not need_token) or token_no_money or token_fail >= TOKEN_FAIL_MAX:
        # A) 没钱/没令: 未达下线阈值 → 退避重试(替代 1.5 秒立即重点);
        #    退避用尽的极端场景回退原重点, 保证 no_action_rounds 仍能推到 3 触发下线/自愈
        if __note_no_action(robot_object, g, need_token):
            return True
        if __start_broker_empty_backoff(robot_object, g, quest):
            return True
        quest.pending = None
        __set_state(g, "READY", __now_ms())
        __goto(robot_object, g, BROKER_NPC_ID, BROKER_NPC_ID, 0, 1500)
        return True
    # B) 需买令但菜单无动作项: 原立即重登 → 改为先退避; 重试仍空才重登(最后手段)
    if __start_broker_empty_backoff(robot_object, g, quest):
        return True
    __need_relogin(robot_object, g, "钟馗空菜单重试仍无动作项 → 重登恢复")
    return True
```

### 3.5 READY 退避守卫（L2635-2637，「找钟馗接取」之前）
