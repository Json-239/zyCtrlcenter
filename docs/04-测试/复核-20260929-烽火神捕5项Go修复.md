## 2. 逐项核验

### ① af78595 满额表落盘 — 通过

- `EnableShareDailyFullPersist(path)`：path 空=纯内存；文件不存在=(0,nil) 首次；解析失败=err（调用方记日志按未满）；**载入只收今日**（跨日惰性失效不变）。
- `MarkShareDailyFull`：写入前**清非今日条目**（文件不随天数增长）→ 锁内 marshal → **锁外** `writeFileAtomic`（对空 path/空 raw 短路，已核实）——失败静默不阻塞下发。
- main 装配 `<DataDir>/share_daily_full.json` ✅。
- **自写断言**（2 组）：往返（3 条→文件 JSON 3 条→新实例载入 3 条→✓ 命中）；**文件侧清旧**（塞昨天条目→Mark 后被清，条目数=4）；损坏容错（err 不阻断→Mark 覆盖重建→可载 1 条）；未配路径纯内存（无文件）。
- **攻击点 4 数据流走查**（合成分支）：`st.full = ShareDailyFullToday` → `full && !hasKey` → 合成 `{done:limit,state:done,marked:true}` → 前端 `N/N ✓`；**可见性门** `!Online && queue空 && !visible` 中 `visible=intentHit||full` → 离线完成号不跳过 ✅。坏版推演：无落盘 → 重启 full=false → 离线行整体消失（现场"一天零完成"）——与我的坏版断言一致。跨日=载入丢弃；损坏=降级无 ✓；均正确。
