# 测试规范

> 本文件是**测试规范单一事实源**（复刻自参考项目 `robot/ctrlcenter/docs/测试框架.md`，适配 Go）。
> 新增测试必须遵守；改规范必须同步本文件与 [覆盖现状](覆盖现状.md)。
> 基座 API 见 [测试基座](测试基座.md)；夹具规则见 [夹具规范](夹具规范.md)。

---

## 0. 目标

1. **统一测试位置**：所有用例放 `test/`，按被测模块分目录，**其他目录不允许出现 `_test.go`**。
2. **能单项测试**：任意用例可独立运行（`go test ./test/event/ -run TestXxx -v`）。
3. **复用基座**：夹具加载、假机器人、临时环境、等待断言全部抽到 `test/testsupport`，新测试零重复造轮子。
4. **每模块一份 README**：记录被测对象 / 测试文件 / 前置条件 / 运行方式 / 覆盖清单 / 已知限制。
5. **统一断言**：一律 Go 原生 `testing` + `t.Fatalf/t.Errorf`，禁止自造 `check()` 式「假通过」。

---

## 1. 目录结构

```
test/
├── README.md                    测试库总索引（目录约定 + 运行方式 + 铁律摘要）
├── testsupport/                 共享基座（唯一允许被各模块共同依赖）
│   ├── README.md
│   └── testsupport.go
├── fixtures/                    夹具（本目录只放夹具与说明，不放用例）
│   ├── README.md                来源与 provenance 规则
│   ├── events/*.json            报文夹具（真实抓包 + 显式构造）
│   ├── chains/*.json            链数据夹具（真实导出裁剪）
│   └── fixtures_test.go         元测试：强制 provenance 规则
├── store/                       每个被测模块一个目录：
│   ├── README.md                固定六段（见 §5）
│   └── store_test.go            包名 <模块>_test，只用被测包的导出 API
├── ctrl/  event/  api/  chainlib/  wsutil/  config/   （同上）
```

**为什么用例放独立 `test/<模块>/` 而不是贴着源码？**
用例只能使用被测包的**导出 API**，天然防止测试依赖内部实现细节；测试与实现目录一眼可分。

## 2. 命名规范

| 项 | 规范 | 示例 |
|---|---|---|
| 目录 | `test/<被测模块>/` | `test/event/` |
| 文件 | `<被测模块>_test.go` | `ctrl_server_test.go` |
| 包名 | `<模块>_test`（外部测试包） | `package event_test` |
| 函数 | `Test<行为或场景>`，一个函数只测一个行为 | `TestGhostOfflineAutoRemoveWhenEnabled` |
| 用例内数据 | 优先用夹具里的真实值（账号/任务号） | `accError = "robot0001032@xy3.com"` |

## 3. 五条铁律

### 3.1 先隔离后使用（数据目录）

- 一律 `t.TempDir()`；**任何用例不得读写项目真实 `data/`、`logs/`、`config.local.json`**。
- `logging.Logger` 必须在 `t.Cleanup` 关闭（Windows 下未关闭会导致 TempDir 清理失败）。
- 例外：`test/chainlib` 允许**只读**读取项目 `data/chains`（可选资产），缺失时自动 skip。

### 3.2 副作用必须可控

- 不拉起机器人进程、不调用真实 `taskkill/tasklist`（进程管理用例用假路径 + `process.New`，不调 `EnsureRunning`）。
- 控制通道用 `Port=0`（系统分配），不占用 27200；不连生产端口/真实机器人。

### 3.3 断言结果证据（禁止只断言「调用了函数」）

- 断言**结果证据**：状态迁移（`state.Get`）、落盘数据（`StoreHasType`/`ReadTail`）、
  广播内容（`SetBroadcast` 捕获）、**机器人端实际收到的命令**（`FakeRobot.ReadCmd`）。
- 反例（不允许）：只断言 `if !called { t.Fatal() }` 这类「调用发生」证据。
- 三类失败都要断言清楚：「能自愈的失败」断言自愈动作 + 重试；「明确失败」断言原因 + 退避；
  「未知回包」断言已上报（fail-loud）。

### 3.4 必须有实际数据支撑（硬规则）

- 报文与输入**尽量取自真实抓包**：夹具放 `test/fixtures/`，每条带 `provenance`：
  `real`（bool，必填）、`trimmed`（bool，必填）、`how`（非空，必填）、`raw`（`real=true` 时必填）、`source`（建议）。
- **构造数据必须显式 `real=false`**，并在 `how` 写清构造依据（哪份协议表/文档）。
- `real=true` 的夹具，其 `event`/`chain` 必须与 `raw` 原文一致（不得改字段）。
- **元测试强制校验**：`test/fixtures/fixtures_test.go::TestFixtureProvenance`（不满足即全量失败）。
- 无法抓包的场景（如 `status_reply` 不落历史）只能用文档示例构造并显式 `real=false`。

### 3.5 模块级状态不跨用例泄漏

- 全局缓存（位置合并器、批处理表）在用例内新建实例（`NewTestHandler`），不复用包级全局。
- 环境变量用 `t.Setenv`（自动还原）；不使用 `init()` 副作用。

## 4. 运行入口

| 诉求 | 命令 |
|---|---|
| 全量（推荐） | `run_tests.bat`（vet → test → 可选 race；**退出码汇总三者**，任一失败即非零） |
| 全量（手动） | `go test ./test/... -count=1` |
| 单模块 | `go test ./test/store/ -v` |
| 单用例 | `go test ./test/event/ -run TestErrorFixtureRecordsCodeRepeatAndFailedList -v` |
| 竞态 | `go test ./test/... -race`（需 CGO/gcc；`run_tests.bat` 自动探测，无 gcc 时跳过） |
| **留档/复现（报告）** | `go run ./tools/test_report` → 写 `docs/04-测试/报告-YYYYMMDD.md` + `data/test_report.json`（含链数据闸门结论与链数据指纹）；**并校验 `覆盖现状.md` 的用例数与实测一致**，不一致非零退出 |
| 文档数字回写 | `go run ./tools/test_report -write`（只改「用例数」列与合计行，说明/链接原样） |

## 5. README 模板（每个模块目录一份，六段必填）

```markdown
# <模块> 测试说明

## 被测对象
- 模块：`internal/xxx/xxx.go`
- 关键函数：`A` / `B`

## 测试文件
| 文件 | 覆盖场景 |
|---|---|

## 前置条件
- 隔离方式 / 使用了哪些夹具 / 是否联网

## 运行方式
- 单项：`go test ./test/xxx/ -run TestYyy -v`
- 模块级：`go test ./test/xxx/ -v`

## 覆盖场景清单
| 用例 | 场景 | 预期 |
|---|---|---|

## 已知限制
- 未覆盖的场景
```

## 6. 决策结论

| 编号 | 事项 | 结论 |
|---|---|---|
| D1 | 框架 | Go 标准 `testing`（零依赖） |
| D2 | 用例位置 | 统一 `test/<模块>/`，外部测试包，禁止贴源码 |
| D3 | 基座 | `test/testsupport`（夹具/假机器人/临时环境/等待断言） |
| D4 | 数据支撑 | 真实抓包夹具 + provenance 元测试强制校验 |
| D5 | 一键运行 | `run_tests.bat`（vet + test + 可选 race，退出码汇总）；留档/复现用 `go run ./tools/test_report`（写报告 + 校验覆盖现状数字） |
| D6 | README | 每模块一份（§5 模板，六段必填） |
| D7 | mock 游戏服 | 不做（中控不碰游戏协议） |
| D8 | 覆盖率工具 | 暂不接入（用例少、全绿即可；需要时加 `-cover`） |
