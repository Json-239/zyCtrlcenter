### 2.3 与既有"回收给抓鬼"路径的交互（不会双回收/互抢）

### 2.4 cutByPoolQuota 截断语义（深挖项）

`internal/api/autotask.go:559-568`：返回**尾部**超出配额的号（`q==0` 返回全量深拷贝；`q<0 || len<=q` 返回 nil）。壳层 `roampoolReclaimDaily`：

```go
if cut := a.cutByPoolQuota(accs, kind, false); len(cut) > 0 {
    a.Log.Printf("…池配额截断 %d 个…")
    accs = accs[:len(accs)-len(cut)]   // cut 必为 accs[q:] 后缀 → 前缀保留 = 配额外允许的号
}
```

**语义核对正确**（cut 是后缀，去掉尾部 q 个后剩前 q 个可派）。第三参数 `manual=false` → 自动通道口径：池停用 → 配额 0 → 全截（一致，`poolAllowsDispatch` 同源）。`LaunchTask`/`launchShareDailyOf` 内部**不再**截断，壳层显式截断是唯一的配额闸，无重复扣减。

### 2.5 防重派闭环与"机器人端收到即停游荡"的假设

- 重派闭环：SendCmd 成功即记台账（`launchShareDailyOf` 内 `MarkShareDailyAssigned`）→ 下一轮 keeper/候选均被 `shareDailyInFlightTodayOf` 拦住；另有 120s 在途 TTL 与候选池配额（在跑+在途）双保险。**不会因"命令尚未生效"被重复回收**。

### 10.1 精读结论（逐文件）

- **state/state.go**：`Robot.BagFullAgeMS int64`（json `bag_full_age_ms,omitempty`，int64 毫秒）。注释口径=0/缺失为未知/从未；不要求会话 enabled；与 `m_share_daily.bag_full_ms` 同源。字段插入未破坏既有字段对齐（Equip/Summons/Booth 仅缩进调整）。
