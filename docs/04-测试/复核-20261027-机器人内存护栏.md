## 7. 残余项
**P2**
1. PowerShell 单点依赖：OOM 时采样可能失败→不动作；且只看机器人，不监控主机剩余提交（本次事故是总和超限）。建议 Win32 `GetProcessMemoryInfo`（stdlib syscall.LazyDLL）兜底 / 叠加 `FreeVirtualMemory` 闸。
2. 窗口 90min/24h vs 泄漏 ~45.8MB/h：若跨过 2200 发生在 06:30 后，最坏 ~21.8h 后先触 3200 → 约 5–8% 周期退化为白天 urgent 重启。建议 urgent 提至 3400–3600 或加第二窗口。
3. 采样失败仅 60min 节流日志，无事件/面板告警；无法区分"机器人未运行"与"采样器失效"。
4. 仅覆盖本机当前部署目录单进程；多实例/远程实例不在范围（应写入运维文档）。
5. 重启前未预检 `ExeExists`，失败后按 180min 冷却：若 exe 缺失/被杀软锁定，会"先杀后起失败"且 3 小时内不重试（看门狗只管中控、不管机器人）→ 建议预检 + 失败短退避（5/15/30min 有界）+ 事件告警。
**P3**
1. `restarts_today` 仅在下一次重启时跨日清零（`robotguard.go:374-378`），跨日无重启会显示昨日值。
2. Log=nil panic（`robotguard.go:263`）；`a.guard` 无锁赋值（:261）。
3. `orphans.go:25-29` 单引号未转义、盘根前缀过宽；`config.go:254` 注释与实现不符。
4. `Dashboard.vue:1285-1290` 新增行有行尾空格（不影响构建）。
5. `store.js:134` `||` 合并导致后端降级时旧值残留。
