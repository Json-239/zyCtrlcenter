## 6. 残余（P3，不阻塞）

- **P3-1 有损映射可撞名**：sanitize 是归一化，不同 key 可能映射到同一 slug（如 `201-test` 与 `201 test`，`测试服` 与 `测 试服`）。后果=第二次创建被预检"目标已存在"拒绝（安全失败、不会覆盖），但 Detail 不指明与哪个 key 撞名。
