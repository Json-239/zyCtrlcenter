**范围**：只改前端 1 个文件 —— `web/src/components/Dashboard.vue`
（`startRow` 逻辑 + 1 处 import 补漏 + 2 处 tooltip 文案；无 Go、无 `.py` 改动）

**未做**：未重启任何进程、未热更、未部署（部署由主控执行）。

## 一、现象（用户原话）

> 在大屏的列表点击**单个启动**不会自动分配适合的任务链路
> （点一个 ≥31 级的抓鬼号，没有走 `ghost_start`，而是发了页面顶部的指定链）

批量「全部启动」是正常的；只有**行内单个「启动」**不按意图。

---

## 二、根因

`startRow` 复用了 `startBody()`，而 `startBody()` 的 `auto` 取决于**页面顶部「启动链路」选择器**：

```js
const autoMode = computed(() => chains.id === 'auto' || !chains.id)   // 105 行

function startBody(accounts) {           // 117-123 行
  const body = {}
  if (autoMode.value) body.auto = true   // ← 顶部选「自动分配」才按意图
  else body.chain_id = chains.id         // ← 顶部选了具体链 → 直接发那条链
  if (accounts) body.accounts = accounts
  return body
}
async function startRow(acc) {           // 128-131 行（改前）
  const res = await post('/api/start', startBody([acc]))
  ...
}
```

顶部选择器一从「自动分配」切成具体链（如 `newbie_full`），点行内「启动」发出去的就是
`{"chain_id":"newbie_full","accounts":[<号>]}` —— 后端 `handleStart` 走非 auto 分支
（`handlers.go:296`），只下发指定链，**不会**按该号意图分组派 `start_chain` / `ghost_start`。
≥31 级的抓鬼号拿到剧情链，机器人端按 `already_done` 直接跳过，表现就是"点了没反应"。

后端本身没问题：`auto:true` → `startAuto()` 按意图分组（新手链 / 抓鬼，含抓鬼等级门槛），
成功回带 `mode:"auto"`（`handlers.go:534-539`）。

## 三、修复

### 3.1 `startRow` 强制 auto（不复用 `startBody`）

```js
// 行内「启动」= **强制按该号意图自动分配**（新手链 / 抓鬼），不受顶部「启动链路」选择器影响：
// 单选一个号时要的是"给它派一条合适的链"，而不是页面顶部替它指定的那条。
// 正常路径的提示由 post() 弹出（后端的「按意图自动分配：…」msg）；这里只补"没走 auto"的边界说明。
async function startRow(acc) {
  const res = await post('/api/start', { accounts: [acc], auto: true })
  if (res && res.ok && res.mode !== 'auto') {
    toast('没走意图自动分配（后端未返回 auto），已按指定链下发', 'warn')
  }
}
```

- **`startAll`（批量）一行没动**：仍走 `startBody(null)`，跟随顶部选择器（设计如此）。
- 边界（要求 4）：后端没回 `mode:"auto"` 且请求成功时，补一条独立的 warn 提示；
  `ok:false` 时 `post()` 已把后端 msg 弹出来，不再叠一条。

### 3.2 补 `toast` 的 import（**改前这里是坏的**）

```diff
 import {
   state, post, stateLabel, statePhrase, stateTagClass, fmtTime, fmtAgo,
   mapLabel, posLabel, posPxLabel, zoneFullLabel, zones, isActive,
-  avatarChar, avatarStyle, hpPct, hpText, taskLabel, taskHint,
+  avatarChar, avatarStyle, hpPct, hpText, taskLabel, taskHint, toast,
 } from '../store'
```

`Dashboard.vue` 里 5 处调用 `toast(...)`（`startAll` / `startRow` / `onlinePicked` / `autoOnline` /
`restoreNow`），但 `toast` **从来没被 import** —— `<script setup>` 下未声明的标识符会编译成全局引用，
运行时 `ReferenceError: toast is not defined`（浏览器实测证据见 §五.3）。
不补这个 import，本次要求 4 的提示根本弹不出来（且抛错），所以必须补。

### 3.3 两处 tooltip（文案与行为对齐）

```diff
-      <label class="row muted" style="gap:4px" title="「全部启动」与行内「启动」都带这条链">
+      <label class="row muted" style="gap:4px"
+             title="只作用于「全部启动」（整批走这一条链）；行内「启动」按该号意图自动分配，不看这里">
```

```diff
-                <button class="btn sm" @click="startRow(r.account)">启动</button>
+                <button class="btn sm"
+                        title="按该号意图自动分配（&lt;31 级 → 新手链 / 其余 → 抓鬼），不跟随顶部「启动链路」选择器"
+                        @click="startRow(r.account)">启动</button>
```

顶部选择器原来的 tooltip 写的是"两个按钮都带这条链"，本次行为变了，那句话会变成假的，必须一起改。

## 六、未做 / 风险

- **`startAll` 的 auto 分支没动**（按指示保持原样）。但补了 import 后它从"抛错"变成"真的会弹"，
  于是**选择器=自动分配时「全部启动」会把同一条消息弹两遍**（`post()` 弹一次 + 该分支弹一次）。
  要不要删掉 `startAll` 里那一行冗余 toast，等主控定（一行改动，不影响下发行为）。
- 行内「启动」不再有"按顶部链强制下发"的入口。如果确实要拿某个号去跑指定链，当前只能走
  「全部启动」或在顶部换了链之后用别的方式；后端 `POST /api/start` 的 `chain_id` 能力没变。
- 部署仍需主控执行：本次只刷新了 `web/dist/`；中控 API（28082/27200）未重启、未热更。
- 验证用的桩服务/夹具在 `%TEMP%\zyverify\`（stub.py、cleanup.py、post.log、zy_*.json），
  属临时产物，可整目录删除。
