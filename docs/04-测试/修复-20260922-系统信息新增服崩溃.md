# 修复-20260922：系统信息「新增服/新增区/切换」全部失效（整页渲染崩溃）

## 现象
面板「系统信息」页里**无法新增服 / 新增区 / 切换区** —— 点了没反应、列表不更新。

## 根因（两层叠加）

### 1. 后端：空区列表被序列化成 `null`（Go 经典坑）
`internal/services/zones/zones.go` 的 `cloneServers`：

```go
out[i].Zones = append([]Zone(nil), s.Zones...)   // ← 空切片时返回 nil
```

`append(空 nil 切片, 零个元素...)` 返回 **nil**，于是 `GET /api/config` 对于「没有任何区的服」
返回 `"zones": null`（现场：`test-201` / `201-test` 两个空服）。

### 2. 前端：没有空值防护 → 渲染函数抛错 → 整页崩
`web/src/components/SystemView.vue` 模板里：

```vue
{{ s.name }}（{{ s.host }}，{{ s.zones.length }} 区）
```

`null.length` → `TypeError: Cannot read properties of null (reading 'length')`
（浏览器控制台每帧报错，`<SystemView>` render 中断）→ **该页后续内容全部不渲染**，
新增表单/按钮随之失效。

> 触发链：用户此前新增了两个"没有区"的服 → 后端返回 `zones:null` → 从那一刻起
> 「系统信息」页每次渲染都崩 → 表现就是"无法新增切换"。

## 修复
| 层 | 改动 |
|---|---|
| Go | `cloneServers` 改为 `append(make([]Zone, 0, len(s.Zones)), s.Zones...)` —— 空列表保持**空数组**，永不返回 null |
| 前端 | `SystemView.vue` 加防护：`(s.zones \|\| []).length`（对任意脏数据免疫） |

（配套：重启中控加载新二进制；前端由 Vite HMR 即时生效。）
