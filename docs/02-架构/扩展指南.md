# 扩展指南

> 骨架层的扩展套路：**加包 → 加接口 → 加测试 → 加文档**。四步缺一视为未完成。

## 1. 加一个业务模块（例如「账号库」「定时上线」）

1. 建包：`internal/services/<你的模块>/`（业务状态放包内，不进 `state`）；
2. 需要机器人配合时用 `event.Handler.SendCmd(cmd, action)` 下发（自带失败日志）；
3. 需要读机器人状态时用 `state.Snapshot()` / `state.Get(account)`（只读副本，不要去改别人状态）；
4. 需要落历史用 `store.LogEvent(map[string]any{...})`（自动补 `ts`，带 `account` 会同时写单 bot 日志）；
5. 在 `main.go` 装配并在 `api` 注册路由；
6. 在 `test/<你的模块>/` 加用例 + README（规范见 [测试规范](../04-测试/测试规范.md)）；
7. 更新 [HTTP-API](../03-协议/HTTP-API.md) 与 `internal/api/protocols.go`（协议映射页同步）。

> 若模块要周期性做事（如定时编排），照 `event.RunStatusPoller` 的写法：
> 接收 `ctx`、`time.Ticker` 循环、日志首行说明周期、退出即返回。

## 2. 加一条 API

```go
// internal/api/handlers.go
func (a *API) handleFoo(w http.ResponseWriter, r *http.Request) {
    body := readBody(r)              // 读 JSON（容错，空体=空 map）
    // ... 业务 ...
    writeJSON(w, http.StatusOK, map[string]any{"ok": true, "msg": "..."})
}

// internal/api/api.go（Register 内）
mux.HandleFunc("POST /api/foo", a.requireToken(a.handleFoo))  // 高危写接口加 requireToken
```

约定：
- **失败必须给原因**（`ok:false` + `msg`），前端不显示含糊的「操作失败」；
- 下发类接口返回 `ok` 即为「是否成功送达机器人」；
- 破坏性操作（删数据/重启进程）默认套 `requireToken`；
- 路由表同步到 `docs/03-协议/HTTP-API.md` 与 `internal/api/protocols.go`。

## 3. 加一条事件

1. 在 `internal/services/event/event.go` 的 `handlers()` 表加分支（**必须**，否则只落历史）；
2. 若需要展示在状态表：加 `state.Robot` 字段 + `onStatusReply` 映射；
3. `TestEventTableCoversProtocolSpec` 会校验协议表覆盖——把新事件加进该用例的 `required` 列表；
4. 在 `test/fixtures/events/` 补夹具（真实报文优先，构造数据必须 `real=false`）；
5. 更新 [控制通道协议](../03-协议/控制通道协议.md)。

## 4. 加一条链

1. 准备链数据文件 → `data/chains/<chain_id>.json`（模板 `data/chains/_example.json`）；
2. 面板「任务链」页自动出现（`internal/chainlib.List` 扫目录），无需改代码；
3. 若是机器人的默认链：改 `config.DefaultChainID` 或请求里显式带 `chain_id`；
4. 校验：`go test ./test/chainlib/ -v`（透传与列表扫描）。

> 链数据内容**不需要**改 Go 代码：中控只做文件加载与原样透传。

## 5. 加一个前端页面

1. 在 `web/src/components/` 新建 `<XxxView>.vue`（`<script setup>` + `apiGet`/`post`）；
2. 在 `web/src/App.vue` 的 `tabs` 与 `view` 映射里登记；
3. 复用 `web/src/store.js` 的共享状态（3 秒轮询 + WS 即时修补），不要各自起轮询。

## 6. 容易踩的坑

| 坑 | 说明 |
|---|---|
| 在事件处理里做重活 | 事件循环是单协程，慢操作会拖住全部事件；用 `go` + 自带超时 |
| 直接改 `state.Robot` 指针 | 只能通过 `Update/Get/Snapshot` 方法访问（并发安全） |
| 忘了 `MarkRemoved` | 移除账号后心跳会把它复活（见事件与数据流 §3） |
| 用强类型解析链数据 | 真实数据字段形状不统一，必须走 `chainlib` 的透传 |
| 日志写业务语义 | 运行历史是排查用的原始事件流，业务文案写 `log` 事件即可 |
